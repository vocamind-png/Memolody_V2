# คู่มือการเทรนอคูสติกโมเดล (Vocalido AI Training Guide)

คู่มือนี้อธิบายขั้นตอนภาพรวม (Pipeline) สำหรับการสร้างและนำเข้าเสียงนักร้องใหม่ เข้าสู่ระบบเครื่องยนต์สังเคราะห์เสียงของ Vocalido (DiffSinger / SVS Engine)

---

## 1. การเตรียมชุดข้อมูล (Dataset Preparation)
อ้างอิงจากบทบันทึกเสียง `Vocal_AI_Recording_Brief.pdf` ขั้นตอนแรกสุดคือการนำไฟล์ `.wav` ทั้งหมด (Acapella, Dry) มาจัดหน้าตาโฟลเดอร์ให้เหมาะสม

```text
/my_vocal_dataset/
  ├── wavs/
  │    ├── singer_thai_001.wav
  │    ├── singer_thai_002.wav
  │    └── ... 
  └── transcriptions.txt (หรือ .lab)
```
*   ไฟล์เสียงต้องมีความถี่ **44100Hz หรือ 48000Hz (16-bit / 24-bit PCM Mono)**
*   ไฟล์เสียงแต่ละไฟล์**ห้ามยาวเกิน 15 วินาที** เพื่อกันปัญหา GPU Out of Memory (OOM) ตอนเทรน

## 2. การสร้างฉลากติดเสียง (Data Annotation & Alignment)
การเทรน AI ร้องเพลง ไม่ใช่แค่โยนเสียงกับเนื้อเพลงเข้าไป ระบบต้องการรู้ว่า "ตัวอักษรไหน ดังขึ้นที่วินาทีที่เท่าไหร่" (Phoneme-level Alignment)

1.  **G2P (Grapheme-to-Phoneme):** แปลงคำอย่าง "ฉัน" ให้เป็น `ch a n`
2.  **MFA (Montreal Forced Aligner):** คือโปรแกรมมาตรฐานอุตสาหกรรมที่จะช่วยฟังไฟล์เดโมของคุณ แล้วจับเวลาว่าเสียง `ch` เริ่มวิที่ 0.5, เสียง `a` เริ่มวิที่ 0.6
3.  **การวาด MIDI:** หากต้องการทำโมเดล Note-Singer SVS ทั่วไป ต้องมีไฟล์ MIDI จับคู่ประโยค เพื่อบอกว่า `a` อยู่ตรงคีย์ C4 

ผลลัพธ์ของขั้นตอนนี้ คุณจะได้ไฟล์นามสกุล `.TextGrid` หรือ `.csv` กำกับไฟล์ `.wav` ทุกตัว

## 3. การทำ Preprocess เพื่อสกัดคลื่น
สคริปต์ในฝั่งเซิร์ฟเวอร์เทรน (เช่น DiffSinger Framework) จะทำการสูบ `.wav` ของคุณไปตีฟูเป็น Spectrogram สกัดหา Pitch/F0 และ Energy

*   **F0 Extraction:** ใช้เครื่องมือเช่น `Parselmouth`, `Dio` หรือ `Harvest` เพื่อหาความถี่เส้นเสียงมนุษย์ (Pitch curve) ของไฟล์นักร้อง
*   **Mel-Spectrogram:** การสกัดแถบสเปกตรัมที่ซับซ้อนให้เป็นรูปภาพให้ AI มองเห็น

## 4. การตั้งค่าการเทรน (Training Configuration)
ให้สร้างไฟล์ `config.yaml` แล้วกำหนดพารามิเตอร์ของระบบคอมพิวเตอร์คุณ:
*   `batch_size:` 8 ถึง 16 (ถ้าใช้การ์ดระดับ 24GB VRAM เช่น RTX 3090/4090) 
*   `max_epochs:` แนะนำให้รันประมาณ 160,000 ถึง 300,000 steps เพื่อให้เสียงเนียนและไร้หุ่นยนต์
*   `learning_rate:` โดยทั่วไปปล่อยค่า Default ของระบบ DiffSinger
*   **การประเมินผล (Tensorboard):** ขณะเทรน สามารถเปิดเช็คกราฟ Loss ที่ค่อยๆ ไต่ระดับลง

## 5. การส่งออดและการนำเข้า Vocalido Server (Export & Integration)
เมื่อเทรนเสร็จสมบูรณ์ คุณจะได้ไฟล์เช็คพอยต์น้ำหนักของสมอง AI มักจะมีนามสกุล `.ckpt` (Checkpoint) หรือถูกคอมไพล์เป็น `ONNX` ดึงมันออกมาแล้วนำมาติดตั้งใน Vocalido 

**ขั้นตอนการใส่ตัวละคร (Voice Bank) ใน Vocalido-server:**
1. สร้างโฟลเดอร์ชื่อนักร้องใหม่ในไดเรกทอรี `vocalido-server/models/` 
2. นำไฟล์โมเดล (Acoustic Model) วางลงไป 
3. สร้างตารางตัวแปรพจนานุกรมดิคชั่นนารีต้นฉบับ (`dictionary.txt`) 
4. อัปเดตฝั่ง Frontend (`voice-studio.html`) ให้ลิสต์ชื่อตระกูล Preset ใหม่เชื่อมเข้ากับ Voice parameter ชุดรับเสียงนี้

🎉 **เสร็จสิ้นกระบวนการ** AI จะสามารถรับคำสั่ง Note, Lyrics ดึงจากหน้า Timeline ของ Memolody ไปแปลงเป็นเสียงสังเคราะห์ตัวละครดังกล่าวได้ 100%
